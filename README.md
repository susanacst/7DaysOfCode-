# 🌸 Portafolio de Ejercicios - #7DaysOfCode con Alura

¡Hola! 👋  
Este repositorio contiene los ejercicios que realicé durante el desafío **#7DaysOfCode** organizado por Alura Latam. 
Cada día trabajé con un enfoque diferente de **lógica de programación** en **JavaScript**, con el objetivo de practicar, reforzar fundamentos y mejorar mis habilidades como desarrolladora web. 🌱

---

## 📚 Temario por Día

| 📆 Día | 🧠 Tema Principal             | 📝 Descripción |
|--------|-------------------------------|----------------|
| 1️⃣     | Operadores de comparación     | Uso de condiciones simples para evaluar expresiones lógicas. |
| 2️⃣     | DOM   | Captura de datos desde el DOM, validación y muestra dinámica de mensajes. |
| 3️⃣     | Bucles (`for`)                | Repetición de instrucciones, recorrido de listas y patrones simples. |
| 4️⃣     | `Math.floor()` + `if/else`    | Simulación de lógicas con números aleatorios y decisiones condicionales. |
| 5️⃣     | Listas y arreglos             | Manipulación de arrays: acceso, búsqueda e interacción. |
| 6️⃣     | `while` + `switch/case`       | Estructuras de control más complejas para tomar decisiones múltiples. |
| 7️⃣     | Funciones                     | Organización modular del código para mejorar su reutilización y legibilidad. |
